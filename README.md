# CSS PHY Transmitter — FPGA / RTL Project

Synthesizable IEEE 802.15.4 Chirp Spread Spectrum PHY transmitter derived from the supplied assignment, CSS reference document and MATLAB floating/fixed-point artifacts.

## Features

- 1 Mbps and 250 kbps CSS modes (`DATA_RATE` parameter)
- PSDU length 0..127 bytes
- PHR + MATLAB-exact padding behavior
- I/Q demux and bi-orthogonal codeword mapping
- exact 250-kbps interleaver
- preamble + rate-specific SFD
- QPSK + 4-symbol DQPSK feedback
- four generated 6-bit complex chirp ROMs
- even/odd CSK gaps and complex modulation
- signed 8-bit `Tx_real` / `Tx_imag`
- optional integer `SAMPLE_DIV` for clocks that are multiples of 32 MHz
- deterministic golden vectors and MSE scripts
- unit and full-chain self-checking SystemVerilog testbenches
- parameterized Vivado synthesis/implementation scripts
- evidence-driven `make verify` status generator
- deterministic randomized regression and explicit bit-order audit
- Vivado timing/utilization report parser

## Required top-level interface

`rtl/css_phy_tx_top.sv` exposes:

```text
clk
reset
start_Tx
payloadLength[7:0]
payload_wr_en
payload_addr[6:0]
payload_din[7:0]
done_Tx
Tx_real[7:0]
Tx_imag[7:0]
```

The three payload-write signals are the minimal explicit extension needed to populate the assignment's payload RAM before `start_Tx`.

## One-command verification

```bash
make verify
```

This regenerates vectors/ROMs, recalculates MSE, runs all available test groups, detects HDL/EDA tools, and emits strict PASS/FAIL/BLOCKED summaries under `reports/`.

Current tool-independent result in this environment: **46 Python tests PASS**.

To run only the source/reference checks:

```bash
make reference
```

## Run RTL simulation

Requires Icarus Verilog:

```bash
make rtl
```

This runs mandatory unit tests and full-chain sample-by-sample comparisons for both rates and payload lengths 0, 1, 3, 25 and 127.

## Lint

Requires Verilator:

```bash
make lint
```

## MSE

`reports/mse_results.csv` is generated by:

```bash
python3 matlab/mse/mse_analysis.py
```

The RTL follows the supplied MATLAB transmitter's six-bit `floor` quantization. Measured normalized chirp MSE at six bits is **0.000891330083552**, below the assignment threshold of 0.005.

## Synthesis

No FPGA part is guessed. With Vivado and a confirmed part:

```bash
FPGA_PART=<exact-part> DATA_RATE=0 CHIRP_INDEX=1 SAMPLE_DIV=1 \
  vivado -mode batch -source scripts/vivado_synth.tcl
```

Then:

```bash
FPGA_PART=<exact-part> vivado -mode batch -source scripts/vivado_impl.tcl
```

See `docs/FPGA_IMPLEMENTATION.md` before generating a bitstream.

## Verified status vs blockers

Verified here:

- supplied codeword tables reproduced exactly;
- supplied m=1 fixed chirp real/imag vectors reproduced exactly;
- deterministic full-chain software/reference architecture equivalence for both rates;
- MSE sweep and fixed-point output range.

Not claimed here:

- native MATLAB execution (MATLAB unavailable);
- RTL simulation/lint (HDL tools unavailable);
- synthesis/timing/utilization (Vivado + exact part unavailable);
- bitstream/on-board proof (board/pin constraints/hardware unavailable).
