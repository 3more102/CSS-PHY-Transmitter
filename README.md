# CSS PHY Transmitter RTL

FPGA implementation of the IEEE 802.15.4 Chirp Spread Spectrum (CSS) PHY transmitter.

## Structure

- rtl/          Synthesizable Verilog RTL
- tb/           Self-checking Verilog testbenches
- matlab/       MATLAB floating/fixed-point reference models
- vectors/      Golden verification vectors
- scripts/      Regression and automation scripts
- constraints/  FPGA timing/pin constraints
- reports/      Simulation, synthesis and implementation reports
- docs/         Architecture and verification documentation
- reference/    Project assignment and supplied reference documents
