# MATLAB Reference Traceability

Maps every major RTL block to the supplied MATLAB reference sources in
`matlab/original/CSS_PHY_Trasmitter-Floating-Fixed Point/`.
Only behavior present in the supplied reference is claimed.

Reference files used:
- `runMe.m` (fixed-point quantization step, file dumps)
- `simulationParameters.m`, `common/globalSettings.m` (parameters)
- `transmitter/ChirpSpreadSpectrum_Tx.m` (PPDU framing, coding chain)
- `transmitter/chirpModulation.m` (DQCSK modulation + gaps)
- `common/bitInterleaver.m` (250 kb/s permutation)
- `common/chirpSequenceGenerator.m`, `common/raisedCosineGen.m`
- data tables: `codeword_1Mbs.txt`, `codeword_250kbs.txt`,
  `chirpSequenceReal_tofile.txt`, `chirpSequenceImag_tofile.txt`,
  `payload.txt`, `preambleSFD.txt`

## Fixed-point rule provenance

The only real-valued computation in the transmitter is the chirp sequence
(reference document Section 3.1). `runMe.m` line:

```matlab
chirpSequence_Tx = floor ( chirpSequence * (2^(TxDACbitNumber -1)-1) ) ;
```

with `globalSettings.m: TxDACbitNumber = 6`. The RTL reproduces this with
floor-quantized 6-bit signed ROM contents and {-1,0,+1} rotation
coefficients; no rounding, saturation, or truncation is used anywhere else.
RTL-vs-MATLAB verification requires exact integer sample equality
(stricter than any MSE bound).
