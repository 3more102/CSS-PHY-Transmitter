# Fixed-Point Design

## Source behavior

The supplied fixed-point MATLAB transmitter quantizes the transmit chirp as:

```text
floor(chirpSequence * (2^(TxDACbitNumber-1)-1))
```

with `TxDACbitNumber = 6`. The RTL therefore uses signed 6-bit integer chirp ROM values.

## Reproduced MSE experiment

The project acceptance target is normalized MSE < 0.005. For chirp index m=1:

| Bits | Round MSE | Floor MSE | Floor passes 0.005? |
|---:|---:|---:|:---:|
| 2 | 0.186578390405 | 0.911927171160 | No |
| 3 | 0.0231552355281 | 0.0964028825215 | No |
| 4 | 0.00387566161969 | 0.0172898019719 | No |
| 5 | 0.000944631027364 | 0.00385042231689 | Yes |
| 6 | 0.000230739042199 | **0.000891330083552** | **Yes** |
| 7 | 0.0000474192115977 | 0.000206677627636 | Yes |
| 8 | 0.0000136293703087 | 0.0000535940676203 | Yes |

The four chirp indices produce the same measured MSE to numerical precision under the supplied parameter symmetry. The exact tables are regenerated by `matlab/mse/mse_analysis.py`.

The numerical reconstruction was cross-checked against the supplied fixed-point m=1 text vectors with an exact 152-real + 152-imag sample match.

## Signal format table

| Signal / stage | Signed | Width | Fraction bits | Rule |
|---|:---:|---:|---:|---|
| payload/PHR bits | No | 1 | 0 | exact bits |
| mapped chips | logical sign | 1 | 0 | exact table |
| QPSK real/imag | Yes | 3 | 0 | exact integer |
| DQPSK feedback real/imag | Yes | 3 | 0 | unnormalized `1+j` initialization |
| chirp ROM real/imag | Yes | 6 | 0 | MATLAB `floor`, two's-complement |
| CSK multiply partial | Yes | 9 | 0 | full integer product |
| CSK add/sub result | Yes | 10 | 0 | no rounding required |
| `Tx_real`, `Tx_imag` | Yes | 8 | 0 | lossless for verified generated range |

No floating-point, runtime trigonometric function, normalization, or fractional arithmetic is used in synthesizable RTL.
